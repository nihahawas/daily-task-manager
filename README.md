# 📝 Daily Task Manager

A sleek, responsive, and lightweight web application designed to help users organize their daily workflow. Built with a focus on simplicity, this tool ensures you can manage your productivity seamlessly across any device.

## ✨ Features

*   **Dynamic Task Creation:** Add tasks instantly with a simple, intuitive input.
*   **Progress Tracking:** Mark tasks as completed to visually monitor your daily goals.
*   **Quick Deletion:** Easily remove tasks to keep your list clean and relevant.
*   **Fully Responsive:** A "mobile-first" design that works perfectly on desktops, tablets, and phones.
*   **Minimalist UI:** Modern styling with a focus on user experience and readability.

# 📖 How to Use

Add a Task: Enter the task name, select a deadline, and choose the priority.

Filter: Use the filter buttons to view specific categories of tasks.

Complete/Undo: Toggle the "Done" button to cross off completed items.

Theme: Use the "Dark Mode" button in the top right for a night-friendly view.

## 📖 How to Use

* **Add a Task:** Enter the task name, select a deadline, and choose the priority level.
* **Filter:** Use the filter buttons to switch between **All**, **Active**, and **Completed** views.
* **Complete/Undo:** Click the **Done** button to mark a task as finished; click **Undo** to bring it back.
* **Theme:** Use the **Dark Mode** button in the top right to switch between light and dark themes.
